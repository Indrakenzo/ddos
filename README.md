# ddos
DDoS adalah singkatan dari Distributed Denial of Service (Penolakan Layanan Terdistribusi). Ini adalah jenis serangan siber yang bertujuan untuk melumpuhkan atau mengganggu ketersediaan sebuah layanan online—seperti situs web, aplikasi, server game, atau seluruh jaringan—sehingga tidak dapat diakses oleh pengguna yang sah.
